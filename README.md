# NExT Vendas

Análise simples de vendas: faturamento por mês e por categoria a partir de um CSV.

## Como rodar o código

```bash
python analise_vendas.py
```

Não precisa instalar nada: o script usa só a biblioteca padrão do Python.

## Estrutura

```
next-vendas/
├── dados/vendas.csv     # base pública e pequena de exemplo
├── analise_vendas.py    # script de análise
└── README.md
```
